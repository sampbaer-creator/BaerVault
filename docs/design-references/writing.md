# writing — reviewer source notes

Source: https://developer.apple.com/design/human-interface-guidelines/writing
Read: 2026-10-13, using Apple’s public documentation JSON.

Reviewed headings: Best practices.

Use concise practical labels and a consistent voice. Keep errors close to the problem and explain how to recover. Empty states should give a useful next step. Avoid implementation jargon in product flows.

These are paraphrased working notes, not a complete copy of Apple’s guidelines.
