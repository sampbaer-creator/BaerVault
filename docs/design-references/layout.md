# layout — reviewer source notes

Source: https://developer.apple.com/design/human-interface-guidelines/layout
Read: 2026-10-13, using Apple’s public documentation JSON.

Reviewed headings: Visual hierarchy; Adaptability.

Order content by importance. Group and align related elements. Use progressive disclosure, keep functional chrome distinct from content, and adapt to available space, orientation, safe areas, and changes in text size.

These are paraphrased working notes, not a complete copy of Apple’s guidelines.
