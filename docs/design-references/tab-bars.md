# tab-bars — reviewer source notes

Source: https://developer.apple.com/design/human-interface-guidelines/tab-bars
Read: 2026-10-13, using Apple’s public documentation JSON.

Reviewed headings: Best practices.

Navigation items represent destinations, have visible labels, and remain discoverable. Prefer fewer items and avoid overflow tabs. Web adaptation uses five persistent destinations plus a separately labeled menu for the full hierarchy.

These are paraphrased working notes, not a complete copy of Apple’s guidelines.
