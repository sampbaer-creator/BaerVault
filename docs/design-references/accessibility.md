# accessibility — reviewer source notes

Source: https://developer.apple.com/design/human-interface-guidelines/accessibility

Reviewed headings: Vision; Mobility.

Support readable contrast and enlarged text. Give each meaningful state more than a color cue, name controls, keep targets comfortably sized, and offer button or keyboard alternatives to custom gestures.
