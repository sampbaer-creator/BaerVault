# typography — reviewer source notes

Source: https://developer.apple.com/design/human-interface-guidelines/typography
Read: 2026-10-13, using Apple’s public documentation JSON.

Reviewed headings: Ensuring legibility; Conveying hierarchy; Supporting Dynamic Type.

Use readable type sizes and moderate weights. Preserve hierarchy as text grows, use few typefaces, and let layouts reflow rather than truncating important content. Web implementation uses rem units and browser enlargement rather than native Dynamic Type.

These are paraphrased working notes, not a complete copy of Apple’s guidelines.
