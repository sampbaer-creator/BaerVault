# motion — reviewer source notes

Source: https://developer.apple.com/design/human-interface-guidelines/motion
Read: 2026-10-13, using Apple’s public documentation JSON.

Reviewed headings: Best practices.

Make motion purposeful and restrained. Preserve orientation and feedback without distracting from repeated tasks. Honor reduced-motion preferences and never rely on animation as the sole carrier of meaning.

These are paraphrased working notes, not a complete copy of Apple’s guidelines.
